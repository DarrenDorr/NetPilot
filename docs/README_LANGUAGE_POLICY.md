# Язык документации NetPilot

## Основное правило

Вся документация NetPilot по умолчанию создаётся и поддерживается **на русском языке**.

Это правило распространяется на:

- основной `README.md`;
- архитектурную документацию;
- модель безопасности;
- план разработки;
- руководства по установке и настройке;
- документацию для разработчиков;
- инструкции по сборке;
- описание резервного копирования и восстановления;
- документацию по движкам и стратегиям;
- руководства по диагностике;
- шаблоны сообщений об ошибках и запросов на улучшение, если они будут добавлены;
- заметки о релизах и описание изменений;
- пользовательские справочные материалы внутри репозитория.

## Что может оставаться на английском

На английском языке сохраняются только элементы, перевод которых технически не требуется или может нарушить совместимость либо юридическую точность:

- имена классов, методов, пространств имён и API;
- названия пакетов и технологий;
- команды терминала и параметры командной строки;
- имена файлов и каталогов, если они являются частью технического контракта;
- названия внешних проектов и продуктов;
- оригинальные тексты лицензий, уведомлений об авторских правах и иных юридических первоисточников сторонних проектов.

При необходимости рядом с оригинальным лицензионным текстом может быть добавлено русскоязычное пояснение, однако оно не заменяет оригинал.

## Англоязычная версия документации

Если в будущем появится необходимость международной документации, она создаётся как **отдельная дополнительная версия**. Английский текст не должен заменять или делать вторичной русскоязычную основную документацию проекта.

## Требование к новым изменениям

При добавлении нового документа в NetPilot его основной текст должен быть написан на русском языке. При проверке изменений документация на другом языке рассматривается как требующая исправления, если она не относится к перечисленным выше техническим или юридическим исключениям.
