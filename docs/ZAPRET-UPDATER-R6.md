# Zapret Updater R6 — доверие к пакету и безопасная распаковка

## Назначение

R6 закладывает защищённый фундамент установки и обновления Flowseal Zapret до появления реальной сетевой загрузки и замены установленного движка.

На этом этапе NetPilot ещё **не скачивает и не устанавливает** обновления автоматически. Сначала проверяются самые опасные границы: происхождение release asset, SHA-256 и содержимое ZIP.

## Официальный источник

Для Windows NetPilot принимает только ZIP release asset официального репозитория:

```text
https://github.com/Flowseal/zapret-discord-youtube
```

RAR и `tar.gz` на Windows в R6 не используются.

Причины выбора ZIP:

- распаковка поддерживается стандартной библиотекой .NET;
- не нужен сторонний RAR-распаковщик;
- меньше supply-chain зависимостей;
- GitHub публикует SHA-256 digest непосредственно в metadata release asset.

На момент проектирования R6 последний официальный стабильный релиз — `1.10.4`, опубликованный 20.10.2026. ZIP asset имеет SHA-256:

```text
291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34
```

Это значение используется только в тесте модели metadata как известный пример. В рабочем updater digest не должен быть жёстко привязан к версии: он будет получаться из metadata конкретного официального release asset и проверяться перед распаковкой.

## Модель ReleaseAsset

`ReleaseAsset` принимает только согласованный набор:

- версия;
- имя ZIP;
- точный HTTPS URL официального Flowseal release asset;
- размер;
- SHA-256.

Отклоняются:

- HTTP;
- другой домен;
- другой владелец/репозиторий;
- несовпадающая версия в URL;
- query/fragment/userinfo;
- non-ZIP asset;
- слишком большой файл;
- некорректный SHA-256.

## Проверка SHA-256

`Sha256Verifier` вычисляет SHA-256 потоково и сравнивает digest через `CryptographicOperations.FixedTimeEquals`.

Архив не должен распаковываться при несовпадении digest.

## Ограничения архива

До извлечения и во время извлечения проверяются:

- максимум 4096 записей;
- максимум 32 МиБ скачанного asset;
- максимум 64 МиБ одного распакованного файла;
- максимум 256 МиБ суммарно после распаковки;
- максимум 240 символов пути ZIP-записи;
- коэффициент распаковки не выше 200:1;
- staging обязан быть пустым;
- повторяющиеся конечные пути запрещены без учёта регистра;
- символические ссылки запрещены;
- абсолютные пути запрещены;
- имена дисков запрещены;
- `..` запрещён;
- выход за staging после `Path.GetFullPath` запрещён;
- reparse point в staging-пути запрещён;
- фактическое число извлечённых байт сверяется с metadata ZIP.

Таким образом закрываются базовые варианты Zip Slip, archive overwrite и decompression bomb.

## Проверка структуры пакета

После безопасной распаковки пакет должен иметь единственную однозначную структуру Zapret.

Требуются:

```text
bin\winws.exe
lists\
general*.bat
```

Разрешены две схемы:

```text
staging\bin\...
staging\general*.bat
```

или одна каталог-обёртка:

```text
staging\zapret-discord-youtube-<version>\bin\...
staging\zapret-discord-youtube-<version>\general*.bat
```

Если найдено несколько потенциальных корней движка, пакет отклоняется.

После распаковки дополнительно проверяется отсутствие reparse point во всём дереве.

## Чего R6 намеренно ещё не делает

R6 не включает:

- HTTP-клиент получения GitHub release metadata;
- скачивание asset;
- автоматический redirect;
- запись в `%ProgramFiles%`;
- переключение каталога `current`;
- удаление старой версии;
- rollback;
- IPC-команды установки или обновления.

Эти операции нельзя подключать до того, как доверие к входному пакету станет отдельным тестируемым слоем.

## План следующей итерации

Следующая итерация updater должна добавить:

1. получение release metadata только из точного GitHub API endpoint официального upstream;
2. выбор только стабильного immutable release;
3. выбор единственного ZIP asset с SHA-256 digest;
4. сетевые тайм-ауты и ограничения размера ответа;
5. строго контролируемую политику redirect;
6. загрузку в защищённый staging;
7. проверку SHA-256;
8. вызов `SafeZipExtractor`;
9. проверку структуры пакета;
10. только после этого — транзакционное переключение установленного `current` с rollback.

## Правило

Ни metadata релиза, ни URL asset, ни путь staging, ни путь установки не принимаются из пользовательского профиля или импортируемого `.npconfig` как доверенные значения.
