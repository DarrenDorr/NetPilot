# Health Check R11

## Назначение

R11 добавляет первый реальный слой проверки доступности ресурсов NetPilot.

Он предназначен для ответа на пользовательский вопрос «Discord / YouTube работает?», а не для чтения содержимого сайтов, авторизации в аккаунтах или сбора истории посещений.

## Встроенные ресурсы

На этапе R11:

- Discord: `https://discord.com/`
- YouTube: `https://www.youtube.com/generate_204`

Health-check не использует cookie, логины, пароли, Discord token, Google/YouTube account или другие пользовательские учётные данные.

## Какие данные получает NetPilot

Проверяющий слой использует только:

- код HTTP-ответа;
- время до получения заголовков ответа;
- технический тип сетевой ошибки.

Тело HTTP-ответа не читается и не сохраняется.

## SSRF-защита

В первой версии действует строгий режим public HTTPS only:

- только абсолютный `https://`;
- только TCP 443;
- credentials в URL запрещены;
- `localhost` и `.localhost` запрещены;
- private, loopback, link-local, multicast, documentation и другие непубличные IP-диапазоны запрещены;
- если DNS возвращает одновременно публичный и непубличный адрес, endpoint отклоняется целиком;
- автоматические HTTP redirect отключены;
- до трёх redirect обрабатываются вручную, и каждый новый адрес заново проходит ту же проверку;
- системный HTTP proxy не используется;
- cookie и credentials не используются;
- DNS-адрес проверяется внутри `SocketsHttpHandler.ConnectCallback`, после чего TCP-соединение открывается именно с проверенным IP. Это исключает отдельное повторное DNS-разрешение между проверкой и соединением.

В R11 нет экспертного обхода этой политики.

## Состояния

- `Healthy` — получен HTTP 2xx;
- `Degraded` — endpoint достижим, но вернул ограничение/неожиданный клиентский статус, например 401/403/429;
- `Unavailable` — timeout, сетевой сбой, HTTP 5xx или endpoint отклонён политикой безопасности.

Диагностика возвращает только короткий технический код. Полный URL с query-параметрами не включается в `ResourceHealth`.

## Важная граница

`HealthCheckUris` и `StrategyDomains` — разные данные.

R11 не использует адрес проверки как домен для маршрутизации Zapret. У встроенных Discord/YouTube список `StrategyDomains` пока намеренно пустой. Домены применения стратегии будут добавляться отдельным этапом после проверки источников и поведения движка.

## Следующий этап

После стабилизации R11 health-check можно использовать в автоматическом выборе стратегии:

1. проверить текущую стратегию;
2. при подтверждённом отказе протестировать ограниченный набор альтернатив;
3. оценить результат по доступности и задержке;
4. не переключаться из-за единичного кратковременного сбоя.
