# Zapret Engine Integration R2

## Назначение

R2 преобразует безопасный `ZapretStrategyTemplate` из R1 в `ZapretLaunchPlan`.

`ZapretLaunchPlan` содержит только:

- абсолютный проверенный путь к `winws.exe`;
- проверенный рабочий каталог `bin`;
- список отдельных аргументов `ArgumentList`.

На этом этапе процесс **не запускается**.

## Разрешение путей

Корень движка должен существовать и не быть symlink/reparse-point.

Внутри него обязательны:

```text
<engineRoot>/bin
<engineRoot>/lists
```

Оба каталога должны быть прямыми дочерними каталогами доверенного корня и не быть reparse-point.

`winws.exe` разрешается только как:

```text
<engineRoot>/bin/winws.exe
```

Файлы, указанные через `%BIN%` и `%LISTS%`, разрешаются только внутри соответствующих каталогов. Проверяются:

- канонический полный путь;
- нахождение внутри доверенного корня;
- существование файла;
- отсутствие reparse-point у файла и каждого промежуточного элемента пути.

## GameFilter

`%GameFilterTCP%` и `%GameFilterUDP%` не подставляются как произвольный текст.

Допускаются только списки портов и диапазонов, например:

```text
443
27015-27050
443,27015-27050,50000-50100
```

Каждый порт должен находиться в диапазоне `1..65535`. Для диапазона начало не может быть больше конца.

Строки, способные добавить новый аргумент или управляющую конструкцию, не проходят разбор как список портов.

## Почему используется ArgumentList

R2 намеренно хранит каждый параметр отдельно:

```text
ExecutablePath = C:\...\bin\winws.exe
ArgumentList[0] = --wf-tcp=80,443
ArgumentList[1] = --filter-udp=443
...
```

Не создаётся строка вида:

```text
winws.exe <единая строка командной оболочки>
```

На следующем этапе это позволит передавать элементы напрямую в `ProcessStartInfo.ArgumentList` без shell-интерпретации.

## Совместимость с текущим Flowseal

При дополнительной сверке upstream обнаружены официальные стратегии с именами не только `ALT*`, но и, например:

- `general (SIMPLE FAKE).bat`;
- `general (FAKE TLS AUTO).bat`.

Каталог обновлён: безопасно допускаются идентификаторы из латинских букв, цифр, пробелов, `_` и `-`. Для внутреннего идентификатора разделители нормализуются:

```text
SIMPLE FAKE   -> SIMPLE_FAKE
FAKE TLS AUTO -> FAKE_TLS_AUTO
```

Таким образом NetPilot не привязан только к ALT-стратегиям.

## Граница R2

R2 всё ещё не:

- запускает `winws.exe`;
- устанавливает WinDivert;
- создаёт/удаляет службы движка;
- выполняет `service.bat`;
- вызывает shell;
- включает привилегированную операцию `EngineStart`.

## Следующий этап

Перед первым реальным запуском Windows-адаптер должен:

1. повторно проверить путь/ACL бинарника непосредственно перед запуском;
2. использовать только `ProcessStartInfo.ArgumentList`;
3. установить `UseShellExecute = false`;
4. не использовать PATH для поиска `winws.exe`;
5. запускать процесс только из защищённого каталога движка;
6. получить отдельный типизированный IPC DTO;
7. реализовать безопасное хранение PID/дескриптора и остановку только собственного процесса;
8. пройти Windows integration tests и CodeQL.
