# Zapret Updater R10 — Windows runtime restore

R10 реализует выбранное поведение **вариант A** для Windows: если Zapret был запущен до обновления, NetPilot запоминает точный `StrategyId`, останавливает процесс перед транзакционным переключением версии и после успешной установки пытается запустить **только ту же стратегию**.

## Правила восстановления

1. До остановки читается runtime snapshot через `ZapretEngineController`.
2. Если движок был остановлен, после обновления он остаётся остановленным.
3. Если движок был запущен, сохраняется точный `StrategyId`.
4. После установки новая версия заново обнаруживает официальные стратегии.
5. Запускается только стратегия с тем же `StrategyId`.
6. Если стратегия исчезла, стала несовместимой, неоднозначной или не запускается, NetPilot не выбирает другую стратегию автоматически.
7. Успешно установленная версия при ошибке восстановления стратегии не откатывается автоматически. Результат содержит явный `RuntimeRestore = Failed` и код причины.
8. Если сама файловая транзакция установки завершается ошибкой после остановки runtime, NetPilot best-effort пытается восстановить прежнюю стратегию уже на восстановленном `current`.

## Граница безопасности

R10 не добавляет `UpdateApply`, `EngineInstall`, `EngineRepair` или другие update-команды в privileged IPC. Разрешённые IPC-операции службы остаются `EngineStart` и `EngineStop`.

`WindowsZapretUpdateRuntimeGate` не принимает путь, URL, BAT-команду или произвольные аргументы. Он работает только с уже известным `StrategyId` и существующим безопасным `ZapretEngineController`.

## Health-check

В текущем Core уже есть модель `ResourceDefinition.HealthCheckUris`, но отдельного production HTTP health-check слоя ещё нет. R10 поэтому **не подменяет проверку доступности ресурса проверкой факта запуска процесса**.

Следующий слой должен выполнить реальные ограниченные health-check запросы Discord / YouTube / пользовательских ресурсов после успешного `RuntimeRestore = Restored`, с отдельными таймаутами, SSRF-защитой и без логирования чувствительных URL/query-параметров.
