# Windows Installer R14

## Цель

R14 превращает собранные компоненты NetPilot в обычный Windows-установщик `NetPilot-Setup-<version>-x64.exe`.

Первая версия установщика ориентирована только на Windows 10/11 x64. ARM64 намеренно не считается совместимой платформой, потому что сетевой движок Zapret/WinDivert в Windows использует kernel-компоненты, для которых x64-эмуляция пользовательских приложений не является гарантией совместимости драйвера.

## Что устанавливается

```text
%ProgramFiles%\NetPilot\
├── App\
│   └── NetPilot.exe + self-contained .NET/Avalonia runtime
├── Service\
│   └── NetPilot.Service.exe + self-contained .NET runtime
├── Engines\
│   └── Zapret\        # создаётся пустым; наполнение — отдельный этап
└── Docs\
    ├── LICENSE.txt
    └── THIRD-PARTY-NOTICES.md
```

Пользователю не требуется заранее устанавливать .NET 10 Runtime.

## Служба Windows

Имя службы: `NetPilot.Service`.

Отображаемое имя: `NetPilot Service`.

Учётная запись: `LocalSystem`.

Путь к исполняемому файлу задаётся абсолютным путём внутри `%ProgramFiles%\NetPilot\Service`.

Service Control Manager ACL после установки разрешает полное управление только:

- `LocalSystem`;
- локальной группе `Administrators`.

Обычный пользователь не должен управлять службой через `sc.exe`; приложение использует отдельный защищённый IPC-контракт.

## Обновление поверх существующей версии

Перед записью новых файлов установщик:

1. проверяет наличие `NetPilot.Service`;
2. отправляет запрос на остановку через абсолютный `%SystemRoot%\System32\sc.exe`;
3. ожидает подтверждённое числовое состояние `SERVICE_STOPPED`;
4. если служба не остановилась в ограниченный срок — отменяет установку;
5. только после этого заменяет файлы;
6. заново фиксирует абсолютный `binPath`, режим автозапуска, ACL и recovery policy;
7. запускает службу.

Такой порядок уменьшает риск частично обновлённой службы и не использует `cmd.exe`/PowerShell для управления службой.

## Recovery policy службы

При аварийном завершении службы допускаются две автоматические попытки запуска:

- через 5 секунд;
- через 15 секунд.

После этого Windows не должна бесконечно перезапускать повреждённую службу.

## Удаление

Uninstaller до удаления файлов останавливает и удаляет службу. Затем удаляются приложение и системный каталог движков.

Будущие пользовательские данные в `%LocalAppData%\NetPilot` намеренно не должны удаляться автоматически обычным uninstall. Для полного сброса будет отдельное явное действие в интерфейсе.

## Inno Setup supply chain

R14 фиксирует Inno Setup `7.1.0 x64`.

Сборка допускается только после двух независимых проверок скачанного файла:

1. SHA-256 должен совпадать с digest официального immutable GitHub release;
2. Authenticode должен иметь статус `Valid`, а сертификат подписанта должен принадлежать `Pyrsys B.V.`.

Закреплённый SHA-256:

```text
0362a383ed217d4c4239b5933866dd96d3eb2102737da92f80f6057a4b40df2f
```

## Что R14 пока не делает

R14 сам по себе не загружает Zapret при установке и не открывает `UpdateApply` через IPC. Это отдельная граница безопасности следующего этапа.

Также R14 пока не имеет публичной code-signing подписи NetPilot. Поэтому Windows SmartScreen может показывать предупреждение для alpha-сборки.
