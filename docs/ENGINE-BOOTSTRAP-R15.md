# Engine Bootstrap R15 — первичная привязка пользователя и установка Zapret

## Цель

R15 превращает установленный NetPilot в первый практически используемый сценарий: после установки GUI может определить отсутствие Zapret и по явному нажатию пользователя установить официальный сетевой движок.

При этом R15 не открывает универсальный updater и не разрешает управление службой другим локальным пользователям.

## Привязка установки к пользователю Windows

На новой установке NetPilot используется одноразовая регистрация владельца:

1. повышенный установщик записывает в `%ProgramFiles%\NetPilot\Config\enrollment.session` Session ID своего интерактивного сеанса;
2. `NetPilot.Service` запускается от `LocalSystem` и создаёт криптографический 256-битный nonce в `enrollment.nonce`;
3. установщик запускает специальный режим установленного `NetPilot.exe` через `ExecAsOriginalUser`;
4. GUI-процесс подключается к Named Pipe, а служба получает его PID, Session ID и SID непосредственно из Windows token/pipe APIs;
5. служба принимает регистрацию только при одновременном совпадении одноразового nonce и ожидаемой Session ID;
6. SID берётся только из проверенного Windows-токена и никогда не принимается из JSON;
7. SID сохраняется в `authorized-user.sid` под защищённым системным каталогом;
8. nonce и session marker немедленно удаляются;
9. повторно заменить владельца через IPC нельзя.

Обычные IPC-команды до завершения регистрации отклоняются с `EnrollmentRequired`. После регистрации запросы другого SID отклоняются с `UnauthorizedUser` до выполнения привилегированной операции.

Администраторы Windows не рассматриваются как изолируемая граница: локальный администратор и без NetPilot способен изменять службу и файлы в `Program Files`.

## IPC v3

R15 повышает версию локального протокола до `3` и использует имя pipe `NetPilot.Service.v3`.

Новые типизированные команды:

- `EnrollAuthorizedUser` — только одноразовый nonce; SID не передаётся;
- `ZapretGetInstallationStatus` — read-only состояние установки;
- `ZapretInstallLatest` — без URL, пути, имени архива, digest, аргументов процесса или shell-команды.

Неизвестные JSON-поля по-прежнему запрещены.

## Первая установка Zapret

`ZapretInstallLatest` разрешена только когда `current` ещё отсутствует и capability `EngineInstall` включена явно.

Служба сама использует существующий защищённый pipeline R6–R10:

- точный allowlist официального Flowseal GitHub;
- проверенная metadata релиза;
- HTTPS без cookies и пользовательских credentials;
- SHA-256;
- повторная локальная проверка asset;
- безопасная ZIP-распаковка;
- запрет Zip Slip/reparse point;
- staging только внутри защищённого engine root;
- транзакционная установка;
- cleanup временных файлов.

Если Zapret уже установлен, `ZapretInstallLatest` возвращает `ZapretAlreadyInstalled`. Обновление существующей версии в R15 намеренно не разрешено.

## GUI

Если служба подтверждает, что движок отсутствует, интерфейс показывает кнопку **«Установить сетевой движок»**.

Нажатие является явным действием пользователя. NetPilot не скачивает и не устанавливает Zapret автоматически при старте программы.

После установки движок остаётся остановленным. Первичный запуск/подбор стартовой стратегии будет отдельным этапом, чтобы R15 не вводил скрытое переключение сетевого трафика.

## Тайм-ауты

Обычные IPC-операции сохраняют короткий лимит 5 секунд. Только первая установка движка получает отдельный верхний предел 120 секунд. Это не расширяет лимит для других привилегированных команд.

## Проверки R15

Обязательные проверки:

- неправильный nonce отклоняется;
- правильный nonce из другой Session ID отклоняется;
- отсутствие защищённой session-записи блокирует регистрацию;
- второй SID не может заменить владельца;
- install request не содержит пользовательских URL/путей/аргументов;
- Windows installer smoke-test подтверждает появление `authorized-user.sid`;
- после регистрации `enrollment.nonce` и `enrollment.session` отсутствуют;
- uninstall удаляет системное состояние авторизации;
- пользовательские данные вне `Program Files` не удаляются.

## Не входит в R15

- обновление уже установленного Zapret через GUI;
- автоматический запуск первой стратегии;
- фоновый автоподбор;
- Telegram WS Proxy;
- изменение владельца установки без переустановки/отдельной административной процедуры;
- доступ к данным ChatGPT/OpenAI или любым сторонним учётным данным.
