# R44 — проверка подключения совместимого приложения через SOCKS5

**Только лабораторная Windows Alpha**, не доказательство обхода блокировок и не разрешение публичного релиза. Основная последовательность см. [WINDOWS-ALPHA-GUI-SMOKE.md](WINDOWS-ALPHA-GUI-SMOKE.md).

| Уровень | Проверяем | Что НЕ доказывает |
|---|---|---|
| A — runtime | подтверждённый принадлежащий NetPilot user-mode процесс ByeDPI и 127.0.0.1:<порт> | доступ во внешнюю сеть |
| B — ресурс | фиксированный публичный HTTPS health-check через локальный SOCKS5 | работоспособность браузера или другого приложения |
| C1 — внешний клиент | независимый opt-in клиент действительно направил HTTPS-запрос через SOCKS5 | поддержку произвольных протоколов и целевого приложения |
| C2 — приложение | явно настроенная функция приложения работает через указанный SOCKS5 | поддержку остальных функций (UDP/QUIC/голоса/игр) |

**Условия:** Windows standard user, только закреплённый ByeDPI 0.17.3, без UAC, драйверов, WinDivert, изменение system proxy/DNS/firewall запрещено. Использовать только проверенный неизменённый Alpha-пакет. Не применять устаревший privileged R42.12.3 validator для no-admin smoke.

## Контрольный протокол

- [ ] A. Движок запущен и показан локальный динамический порт.
- [ ] B. Отдельно выполнены direct и SOCKS5 проверки одного утверждённого ресурса, видны маршруты и коды.
- [ ] C1. Независимый клиент явно использовал локальный SOCKS5 для фиксированного публичного HTTPS endpoint, записан итог HTTP или категория ошибки без раскрытия приватных запросов.
- [ ] C2. Выбранное приложение **имеет собственную поддержку SOCKS5**; настроено вручную и реально проверена конкретная функция. Иначе отметить NOT SUPPORTED, а не PASS.
- [ ] D. После остановки движка listener исчез, новый порт не выдаётся за активный; `ciadpi.exe` не остался.
- [ ] E. System proxy, DNS, firewall, WinDivert и права пользователя не изменены.
- [ ] F. Пакет и приложение идентифицированы по SHA-256 и точному коммиту; результаты логов обезличены.

До C2 с доказательствами не писать «приложение подключено» или «доступ восстановлен». Даже при успехе сохранять `PRODUCTION_ADMISSION=BLOCK` и Draft ByeDPI. Данные можно приложить к [issue #116](https://github.com/DarrenDorr/NetPilot/issues/116) после удаления личной информации.
