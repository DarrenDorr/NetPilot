# GUI R13 — первый функциональный интерфейс

## Цель

R13 переводит Avalonia-интерфейс NetPilot из статической заглушки в первый рабочий пользовательский экран.

## Обычный режим

Главный экран показывает:

- общее состояние;
- Discord;
- YouTube;
- Telegram;
- кнопку `Проверить сейчас`;
- кнопку `Подобрать стратегию`.

Технические термины скрыты по умолчанию.

`Проверить сейчас` выполняет только health-check R11. Эта кнопка **не меняет сетевую стратегию**.

`Подобрать стратегию` является отдельным явным действием пользователя и запускает ограниченную автоматизацию R12.

Telegram пока отображается как ещё не подключённый компонент. До интеграции отдельного Telegram Engine общий статус не должен утверждать, что абсолютно все сервисы NetPilot работают.

## Расширенный режим

Переключатель `Расширенный режим` показывает:

- состояние Zapret;
- ID активной стратегии;
- описание последнего действия.

Обычный режим не показывает stack trace и внутренние исключения.

## Разделение платформ

`NetPilot.App` теперь является библиотекой общего Avalonia UI.

Первый исполняемый host:

`NetPilot.App.Windows`

Он собирает зависимости Windows:

```text
NetPilot.App.Windows
        ↓
NetPilot.App
        ↓
DashboardService
   ↙             ↘
R11 Health      R12 Automation
                    ↓
        WindowsZapretStrategyRuntime
                    ↓
           защищённый IPC
                    ↓
            NetPilot.Service
```

Такой подход не заставляет общий UI ссылаться на `net10.0-windows`. В дальнейшем можно добавить отдельные Linux/Android hosts и сохранить общие ViewModel/экраны там, где это уместно.

## Поведение без службы

Если `NetPilot.Service` ещё не установлен или не запущен:

- интерфейс продолжает открываться;
- публичный health-check Discord/YouTube остаётся доступным;
- технический блок сообщает, что служба недоступна;
- подбор стратегии завершается понятной ошибкой и не пытается обходить IPC.

## Безопасность

R13 не добавляет:

- новых IPC-команд;
- автоматического скрытого переключения стратегии;
- новых привилегий службы;
- OpenAI/ChatGPT-интеграций;
- аккаунтных токенов;
- cookie;
- телеметрии.

Windows GUI host отдельно собирается в CI на `windows-2025` при каждом PR.

## Что остаётся до alpha

После R13 ещё нужны как минимум:

- установка/регистрация Windows Service;
- установка первоначального пакета Zapret через пользовательский сценарий;
- мастер первого запуска;
- tray/background mode;
- Telegram Engine;
- окончательная визуальная полировка;
- полноценный installer;
- финальный security audit перед релизом.
