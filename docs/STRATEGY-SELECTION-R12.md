# Автоматический подбор стратегии R12

## Цель

R12 добавляет ограниченный автоматический подбор стратегии Zapret поверх уже проверенных слоёв:

- безопасного IPC;
- запуска/остановки Zapret;
- health-check Discord/YouTube из R11.

Алгоритм находится в непривилегированном модуле `NetPilot.Automation`. Привилегированная служба не получает универсального API автоматизации и не выполняет health-check HTTP-запросы.

## Поведение

1. Если Zapret остановлен — автоматизация ничего не запускает сама.
2. Если Zapret запущен, текущая стратегия проверяется.
3. Один неудачный результат не приводит к переключению: текущая стратегия должна провалить не менее двух подтверждающих раундов.
4. После подтверждённого сбоя тестируется не более 6 альтернативных официальных стратегий в быстром режиме.
5. Для каждой альтернативы используется только ID из каталога, полученного от службы.
6. Кандидат считается пригодным для автоматического переключения только если все выбранные ресурсы имеют состояние `Healthy`.
7. Среди пригодных кандидатов преимущество имеет более высокий health/latency score.
8. Перед окончательным выбором победитель проходит дополнительный подтверждающий health-check.
9. Если ни одна стратегия не подтверждена, NetPilot возвращает исходную стратегию.
10. Если исходную стратегию восстановить не удалось, результат явно помечается как `OriginalRestoreFailed`.

## Защита от нестабильной сети

Автоматизация не должна переключать стратегию из-за единичного timeout или краткого сетевого сбоя. По умолчанию используется два подтверждающих раунда текущей стратегии с небольшой паузой между ними.

## Ограничение перебора

В R12 действует быстрый режим:

- максимум 6 альтернатив за один автоматический запуск;
- максимум 16 проверяемых ресурсов;
- каталог стратегий ограничен 128 элементами;
- идентификаторы стратегии проверяются на размер и уникальность.

Неограниченный brute-force параметров и генерация тысяч вариантов запрещены.

## Оценка

Внутренняя оценка имеет диапазон 0–100:

- `Healthy` = 100;
- `Degraded` = 45;
- `Checking` = 20;
- `Unknown` = 10;
- `Unavailable` = 0.

Из среднего значения вычитается небольшой latency penalty (не более 15 баллов). Однако автоматический кандидат всё равно считается пригодным только когда **все** требуемые ресурсы `Healthy`; высокий score не может компенсировать недоступный ресурс.

## Windows runtime adapter

`WindowsZapretStrategyRuntime` работает только через существующий `IPrivilegedServiceClient`:

- читает каталог стратегий;
- читает состояние Zapret;
- если уже запущена нужная стратегия — ничего не меняет;
- при смене стратегии сначала требует подтверждённую остановку;
- затем запускает ровно запрошенный StrategyId;
- проверяет, что служба вернула `Running` и тот же StrategyId.

IPC timeout/ошибка протокола не интерпретируются как «плохая стратегия»: такой сбой прекращает автоматический прогон.

## Что ещё не включено

R12 пока не запускается автоматически из GUI и не работает по расписанию. Подключение к пользовательскому интерфейсу, хранение последней рабочей стратегии и политика фоновых повторных проверок будут следующими этапами.
