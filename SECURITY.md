# Политика безопасности

NetPilot пока находится на раннем этапе разработки и не готов к использованию как стабильный производственный продукт.

Безопасность и приватность являются обязательными условиями выпуска. NetPilot проектируется по принципам минимальных прав, `default deny`, локального хранения и отсутствия скрытой телеметрии.

## Изоляция аккаунтов и пользовательских данных

NetPilot не должен автоматически получать доступ к данным других пользователей операционной системы, браузеров, менеджеров учётных данных или сторонних приложений.

NetPilot Core не связан с аккаунтом ChatGPT или OpenAI и не должен читать cookie, сессионные токены, API-ключи, `OPENAI_API_KEY` либо другие данные авторизации OpenAI. Любая потенциальная интеграция с OpenAI в будущем может появиться только как отдельная явно включаемая функция после отдельного анализа безопасности.

Инструменты ChatGPT, использованные разработчиком для работы с GitHub, не входят в NetPilot и не передают программе доступ разработчика к GitHub, ChatGPT, OpenAI или другим аккаунтам.

## Сообщение об уязвимостях

Если во время разработки вы обнаружили уязвимость или другую проблему безопасности, не публикуйте в открытом отчёте секреты, токены доступа, пароли, учётные данные, приватные журналы, содержимое сетевого трафика или иные чувствительные сведения.

В открытом сообщении следует указывать только минимально необходимое техническое описание, позволяющее воспроизвести проблему без раскрытия пользовательских данных.

До выпуска первой публичной бинарной версии NetPilot будет настроен отдельный приватный канал для ответственного сообщения об уязвимостях.
