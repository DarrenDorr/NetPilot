# NetPilot UI Kit v1.1

Утверждённый базовый набор визуальных ассетов NetPilot для будущего интерфейса.

## Визуальный стиль

- тёмный Windows-style интерфейс;
- синие/cyan базовые элементы;
- зелёный — успешная работа;
- красный — ошибка/остановка;
- жёлто-оранжевый — предупреждение;
- серо-синий — не проверено;
- мягкое свечение, скруглённые формы, минималистичная VPN-подобная подача.

## Содержимое

Полный комплект хранится в `NetPilot_UI_Kit_v1_1.zip` и включает 109 отдельных PNG-иконок, размеры 64/128/256 px, мастера по категориям, manifest и базовые SVG.

В папке `svg/` отдельно размещены базовые векторные значки, которые можно использовать напрямую в интерфейсе.

Категории: `core`, `navigation`, `actions`, `status`, `network`, `system`, `services`.

## Сторонние сервисы

Логотипы YouTube, Discord, Telegram, Steam, Twitch, VK, WhatsApp, Instagram, TikTok и других сервисов должны перед публичным релизом быть заменены на официальные бренд-ассеты и проверены по актуальным правилам использования соответствующих брендов.

## Правило для разработки NetPilot

Этот UI Kit является текущим визуальным ориентиром проекта. Новые системные иконки должны сохранять тот же визуальный язык. Сторонние бренд-иконки хранятся отдельно от собственных ассетов NetPilot.
