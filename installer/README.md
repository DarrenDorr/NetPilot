# Установщик NetPilot

Этот каталог содержит Windows-установщик NetPilot на Inno Setup 7.

## Требования

Для обычной локальной сборки нужен только .NET 10 SDK и доступ в интернет. Скрипт `scripts/build-installer.ps1` сам:

1. публикует `NetPilot.App.Windows` как self-contained `win-x64`;
2. публикует `NetPilot.Service` как self-contained `win-x64`;
3. загружает только закреплённый Inno Setup 7.1.1 x64 из официального immutable GitHub release;
4. проверяет SHA-256 установщика Inno Setup;
5. проверяет валидную Authenticode-подпись и издателя `Pyrsys B.V.`;
6. устанавливает Inno Setup в локальный каталог `artifacts/tools`;
7. компилирует `NetPilot-Setup-<version>-x64.exe`.

Текущие release-метаданные и закреплённые build-tool identity хранятся в `release/release-manifest.yaml`. Скрипт сборки остаётся исполняемым источником фактической загрузки/проверки, а R41.1 guard требует согласованности manifest, документации и installer metadata.

Пример:

```powershell
pwsh -File scripts/build-installer.ps1 -Version 0.1.0-alpha -VersionInfoVersion 0.1.0.0
```

Готовый файл появляется в `artifacts/installer`.

## Границы безопасности

Установщик требует административные права, потому что он устанавливает Windows-службу и пишет в `Program Files`.

Он не:

- запрашивает аккаунт ChatGPT/OpenAI;
- читает браузерные cookies;
- устанавливает телеметрию;
- добавляет произвольные команды shell в NetPilot;
- создаёт пользовательские настройки в профиле во время административной установки.

Служба регистрируется под `LocalSystem`, но управление через Service Control Manager ограничивается `LocalSystem` и локальными администраторами. Пользовательский GUI общается со службой только через защищённый Named Pipe NetPilot.

## Обновление поверх существующей версии

Перед заменой файлов Setup пытается корректно остановить `NetPilot.Service` и ждёт подтверждённого состояния `SERVICE_STOPPED`. Если служба не остановилась, установка прекращается вместо замены исполняемых файлов «на горячую».

После копирования новой версии служба перенастраивается на фиксированный путь внутри `{app}\Service`, получает строгий service ACL, политику ограниченного восстановления после аварии и запускается заново.

## Удаление

Удаление:

- останавливает и удаляет Windows-службу;
- удаляет файлы приложения;
- удаляет системный каталог `Engines`;
- не удаляет будущие пользовательские данные из `%LocalAppData%\NetPilot`.

## Подпись релизного установщика

На этапе R41.1 собственного production code-signing сертификата NetPilot всё ещё нет. Поэтому собранный alpha-установщик может вызывать предупреждение Windows SmartScreen о неизвестном издателе. Нельзя подменять это самоподписанным сертификатом и выдавать его за доверенную публичную подпись.

R41.1 только синхронизирует release metadata и licensing hygiene. Он не разрешает production native execution и не добавляет ByeDPI в установщик.
